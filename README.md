# XX科技 — MyCard 數位點數卡專賣商城 (Web & Mobile App)

本專案為 **XX科技有限公司 (XX TECHNOLOGY CO., LTD.)** 之 MyCard 點數卡線上零售平台前端與管理後台系統，支援桌面版寬螢幕與行動版 App 響應式介面。

## 功能架構

### 1. 前台商城與會員系統
- **首頁 (`/`)**：品牌促銷主視覺、常用點數快速導覽、熱門點數面額網格、Bento 會員權益規格、三步驟發卡流程與常見問題。
- **全部商品目錄 (`/products`)**：支援全系列 17 種 MyCard 面額（90 點至 3,290 點）關鍵字搜尋、面額區間篩選與排序。
- **商品詳情頁 (`/products/:id`)**：支援 17 種點數面額一鍵切換、購買張數試算、滿千 1% 儲值金回饋預覽與手機版底部常駐結帳列。
- **購物車 (`/cart`)**：多面額合併結帳、折扣與儲值金回饋明細試算。
- **ATM 虛擬帳號結帳 (`/checkout`)**：支援台灣 25 家銀行代碼選擇（含手動輸入 3 碼）、轉出帳號末五碼綁定與會員儲值金折抵。
- **訂單與數位序號領取 (`/order/:orderNo`)**：提供 16 碼專屬 ATM 虛擬帳號複製，以及入帳核發後的 MyCard 卡號／密碼票卡一鍵複製。
- **會員中心 (`/member`、`/login`、`/register`)**：儲值金餘額查詢與歷史訂單序號永久保存匣。
- **常見問題與關於我們 (`/faq`、`/about`)**：完整退換貨政策、防詐騙聲明與公司營業資訊。

### 2. 管理員發卡與營運後台 (`/admin`)
- **營運總覽 (`/admin`)**：即時營收、待發卡訂單數與 17 種 MyCard 面額庫存監控。
- **專人手動／自動發卡 (`/admin/fulfill`)**：支援一鍵自動抽卡配發或手動貼上 `卡號,密碼`。
- **商品與補貨管理 (`/admin/products`)**：支援線上修改各面額售價、促銷標籤、上下架狀態與批次匯入點數卡序號。
- **訂單與會員管理 (`/admin/orders`、`/admin/users`)**：訂單狀態切換與註冊會員儲值金列表。

## 技術棧
- **前端框架**：React 19 + TypeScript + Vite 6
- **樣式系統**：Tailwind CSS v4 (`src/index.css`)
- **路由與狀態管理**：React Router v7 + Zustand (含 LocalStorage 持久化)
- **圖示庫**：Lucide React

## 本地開發與編譯指令

1. **安裝依賴套件**：
   ```bash
   npm install
   ```

2. **啟動開發伺服器**：
   ```bash
   npm run dev
   ```
   預設開啟於 `http://localhost:5173/`。

3. **打包正式環境靜態檔**：
   ```bash
   npm run build
   ```
   編譯產出位於 `dist/` 目錄。
